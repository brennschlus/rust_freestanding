# Грабли sendkey

Клавиши в гостя через QEMU-монитор ([[Проверка в QEMU headless]]):

- **Перекрывающиеся `sendkey` не складываются** — аккорд слать одной командой: `sendkey a-d-g 1500`.
- После загрузки с `-d int` ждать 20–30 с — иначе клавиши уходят в никуда и кажется, что [[Клавиатура i8042|клавиатура]] сломана.
- Под [[Ловушка wav-бэкенда|wav-бэкендом]] отпускания клавиш приходят с многосекундной задержкой — порядок событий вранье.

Проверять орган и [[Транскрипция|транскрипцию]] вживую: GUI + pipewire, руками.
