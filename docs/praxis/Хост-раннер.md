# Хост-раннер

`cargo run -p officium-host -- [score.off] [--fuel N] [--render]` (из `officium/`) — dev-зеркало [[celebrare]] без QEMU: тот же конвейер парс → [[Тайпчекер — рифма это унификация|чекер]] → §14-проводка по трём телам, `HostPlatform` печатает GRAVITAS-команды, `--render` играет на MockOrgan с логом.

Без аргумента — запечённый [[Метеорный скор|meteor.off]].

Контроль правильности: астероид dv=0.3337, комета 0.0917125, камешек nihil — те же числа обязан выдавать `celebrare` в ядре.

Быстрый цикл: правка → `cargo test` в [[Воркспейс officium|воркспейсе]] (58 тестов) → хост-раннер → и только потом [[Проверка в QEMU headless|QEMU]]/живой GUI.
