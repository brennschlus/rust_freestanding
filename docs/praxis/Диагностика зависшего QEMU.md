# Диагностика зависшего QEMU

Гость молчит/висит — по порядку из монитора:

1. `info registers` — RIP; символизировать через `addr2line` по ELF ядра: `target/x86_64-unknown-none/debug/deps/artifact/…` (не образ!);
2. `info pic` — irr/imr/isr: что замаскировано, что висит недоставленным ([[PIC и маски прерываний]]);
3. `info irq` — счётчики прерываний: тикает ли [[Таймер PIT|таймер]], приходит ли [[Клавиатура i8042|клавиатура]];
4. совсем плохо — `gdb -p <pid qemu>` на сам процесс QEMU (так был пойман [[Почему выкинут SB16|цикл i8257_dma_run]]).

Классика проекта: double fault с SP на дне = переполнение стека ядра (рекурсивный парсер — [[Bootloader и старт ядра|лечится kernel_stack_size]] + depth-guard в [[Плоская форма|парсере]]); #GP после lgdt = [[GDT и TSS|непереза­груженный SS]].
