# PIC и маски прерываний

Классическая пара 8259, ремап на 32–47 ([[IDT и прерывания]]).

Маски задаются **явно**: размаскированы только IRQ 0 (таймер), IRQ 1 (клавиатура), IRQ 2 (каскад) и линия PCI-звука (у SeaBIOS это IRQ 11 для [[AC97 драйвер|AC97]]). Всё остальное замаскировано — меньше сюрпризов от спурьёзных линий.

Level-triggered PCI-линии: сначала write-1-clear статуса устройства, потом EOI — иначе прерывание взводится снова бесконечно.

Диагностика: `info pic` в QEMU-мониторе показывает irr/imr/isr ([[Диагностика зависшего QEMU]]).
