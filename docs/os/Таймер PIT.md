# Таймер PIT

Канал 0 PIT на дефолтной частоте **~18.2 Гц** (~55 мс/тик). Обработчик IRQ 0 минимален: инкремент счётчика `interrupts::ticks()`, EOI, плюс страховочный drain [[Клавиатура i8042|контроллера i8042]] и будильник для [[Async sleep]].

Миллисекунды = `ticks() * 55` — так считает `uptime` в [[Шелл|шелле]] и `now()` у [[celebrare|KernelPlatform]] (микросекунды: `ticks() * 55_000`).

Канал 2 того же PIT занят [[PC speaker|спикером]].
