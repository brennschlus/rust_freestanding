# Ядро — индекс

Freestanding-ядро x86_64 (`kernel/`), таргет `x86_64-unknown-none` (soft-float). Путь туториала Оппермана пройден целиком, дальше — своё.

## Загрузка и память
- [[Bootloader и старт ядра]] — bootloader 0.11, BOOTLOADER_CONFIG, стек 512 КиБ
- [[Пейджинг]] — OffsetPageTable, аллокатор кадров из карты памяти
- [[Куча ядра]] — linked_list_allocator, 100 КиБ

## Прерывания
- [[GDT и TSS]] — IST-стек для double fault; грабли с SS/DS/ES
- [[IDT и прерывания]] — breakpoint, double fault, ремап PIC
- [[PIC и маски прерываний]] — явные маски, level-triggered IRQ
- [[Таймер PIT]] — ~18.2 Гц, тики
- [[Клавиатура i8042]] — порт 0x60, drain

## Кооперативная многозадачность
- [[Async executor]] — Task, TaskWaker, hlt без гонок
- [[ScancodeStream]] — прерывание → очередь → async-поток
- [[Async sleep]] — sleep_ms на тиках таймера

## Интерфейс
- [[Framebuffer-консоль]] — свой вывод, font8x8, скроллинг
- [[Шелл]] — команды, инструменты, [[celebrare]]
