# Пейджинг

`kernel/src/memory.rs`. Виртуальная память поверх маппинга, который сделал [[Bootloader и старт ядра|бутлоадер]]:

- **OffsetPageTable** — вся физическая память доступна по смещению `physical_memory_offset` из `BootInfo`; таблицы страниц читаются как обычная память.
- **BootInfoFrameAllocator** — выдаёт свободные кадры, итерируясь по `boot_info.memory_regions` с `kind == Usable`.
- Page fault handler в [[IDT и прерывания|IDT]] логирует адрес из **CR2** и код ошибки.

Главный потребитель — [[Куча ядра]]: маппит свои страницы через этот аллокатор.
