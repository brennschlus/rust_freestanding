# Почему выкинут SB16

SB16-орган (коммит `4217471`) работал **только под wav-запись**. С живым бэкендом (pulseaudio/pipewire) эмуляция QEMU наглухо вешала окно:

1. sb16 в auto-init режиме держит DREQ вечно;
2. `i8257_dma_run` перевзводит bottom-half без прогресса, когда в аудиобуфере хоста нет места;
3. main loop крутится на 100% CPU → GTK-отрисовка голодает → чёрное неотвечающее окно.

Никакие опции audiodev не лечат. Заменён на [[AC97 драйвер]] с настоящим bus-master DMA (`c56daca`).

## Урок

wav-бэкенд потребляет данные безусловно, поэтому headless-тесты этого **не ловили** — см. [[Ловушка wav-бэкенда]]. Живой тест GUI + pipewire — единственная правда о звуке.
