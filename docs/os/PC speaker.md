# PC speaker

`kernel/src/speaker.rs` — первый звук проекта (2026-07-06): канал 2 [[Таймер PIT|PIT]], порты 0x42/0x43/0x61. `start_tone(hz)` / `stop_tone()`, `note_freq("c4")` → 262 Гц и т.д. (октавы 0–8, равномерная темперация).

Обслуживает `beep`, `play`, `piano` в [[Шелл|шелле]] и служит моно-фолбэком для [[Транскрипция|transcribe]], когда [[AC97 драйвер|AC97]] недоступен.

Проверка звука в headless — через wav-бэкенд QEMU, но осторожно: [[Ловушка wav-бэкенда]].
