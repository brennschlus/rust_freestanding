# Шелл

`kernel/src/task/shell.rs` — async-задача на [[Async executor|executor]]'е: читает [[ScancodeStream]], редактирует строку с эхом в [[Framebuffer-консоль|консоль]], исполняет по Enter.

## Команды

| команда | что делает |
|---|---|
| `help` | список команд |
| `echo <text>` | печать |
| `clear` | очистить экран |
| `uptime` | время с загрузки ([[Таймер PIT]]) |
| `heap` | статистика [[Куча ядра\|кучи]] |
| `beep [hz] [ms]` | писк [[PC speaker\|спикером]] |
| `play <notes>` | ноты вида `c4 e4 g4 c5:800` |
| `piano` | живой инструмент, спикер, моно |
| `organ` | живой инструмент, [[AC97 драйвер\|AC97]], полифония |
| `transcribe` | сыграть фразу → стих Officium ([[Транскрипция]]) |
| `celebrare <s>` | скор Officium: `meteor`, `cantus` или `-` (набрать с клавиатуры) — [[celebrare]] |

Инструменты и `celebrare -` обрабатываются в главном цикле (им нужен сам scancode-поток), остальное — в `execute()`.

Раскладка мануала — см. [[Клавиатура i8042]].
