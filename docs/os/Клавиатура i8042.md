# Клавиатура i8042

Обработчик IRQ 1 читает скан-код из порта **0x60** и кладёт его в очередь [[ScancodeStream]] — никакой логики в прерывании, декодирование в async-задаче (крейт `pc-keyboard`, ScancodeSet1, Us104Key).

## Грабли

- **drain_controller**: i8042 надо вычитывать до пустого статуса, а не по одному байту — иначе контроллер молчит, пока не заберут застрявший байт. Дополнительный страховочный drain делается из тика [[Таймер PIT|таймера]].
- В [[Шелл|шелле]] декодированные символы; инструменты (`piano`, `organ`, `transcribe`) работают на **сырых KeyEvent** (down/up), чтобы нота звучала, пока клавиша нажата.

Раскладка клавиш-нот (общая для инструментов и [[Транскрипция|транскрипции]]): `key_midi` в `kernel/src/task/shell.rs` — z-ряд = октава 3 (белые), a-ряд = октава 4, диезы на w e t y u, `k`=c5, `o l p` = c#5 d5 d#5.
