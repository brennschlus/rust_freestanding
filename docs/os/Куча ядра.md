# Куча ядра

`kernel/src/allocator.rs`: **100 КиБ** по адресу `0x_4444_4444_0000`, страницы замаплены через [[Пейджинг|BootInfoFrameAllocator]], аллокатор — `linked_list_allocator` как `#[global_allocator]`, плюс `extern crate alloc` — работают `Box`/`Vec`/`Rc`/`String`.

`#[alloc_error_handler]` не нужен: паника по умолчанию стабилизирована.

Статистику отдают `allocator::used()` / `allocator::free()` — команда `heap` в [[Шелл|шелле]].

От кучи живёт всё интересное: [[Async executor|таски]], [[Framebuffer-консоль|строки консоли]], целиком [[Воркспейс officium|Officium]] (IR — боксированное дерево, скоупы — Rc-списки).
