# rust_freestandig — карта проекта

Мини-ОС на Rust по мотивам туториала Филиппа Оппермана (bootloader 0.11, framebuffer), выросшая в машину для языка **Officium** — языка, где григорианские лады являются монадами, стихи поются, а клавиатура — мануал органа.

## Три слоя

- [[Ядро — индекс]] — всё железо: загрузка, прерывания, память, звук, шелл.
- [[Officium — индекс]] — язык: лады-монады, IR, машина, парсеры (текст, песня, аудио), тайпчекер.
- [[Практика — индекс]] — как это проверять: QEMU, тулчейн, грабли.

## Сквозной сюжет

Ядро даёт [[Async executor|исполнитель задач]], [[Framebuffer-консоль|консоль]], [[AC97 драйвер|орган]] и [[Клавиатура i8042|клавиатуру]]. Поверх них [[celebrare]] запускает [[Officium — обзор|Officium]]: скор парсится из [[Плоская форма|текста]], [[Литургическая форма|песни]] или [[Транскрипция|живой игры]], проверяется [[Тайпчекер — рифма это унификация|тайпчекером]], озвучивается [[Рендер|рендером]] и исполняется [[CEK-машина и топливо|машиной]], чей единственный выход в мир — [[Граница чистоты|perage]].
