# Тайпчекер — рифма это унификация

M7 (§7.4), `officium-core/src/check.rs`. Два прохода в одном обходе; ошибки = `Dissonance::Discors { versus, msg }` — скор отвергается **до первой ноты** (host и [[celebrare]] зовут `check_program` сразу после парсинга).

## 1. Вывод типов (HM-стиль)
Унификация с subst-вектором и occurs check («стретто, глотающее само себя»). Зеркалит [[CEK-машина и топливо|машину]] точно:
- `Var`: скоуп → [[Билтины|билтины]] → педали;
- оверлоды `resolve` типизируются **в лексическом скоупе вызова**, все real/tonal одного имени унифицируются в один тип;
- `mitte` принимает cmd|plan, `corpus` — genus|str: отложенные предикаты «один из»;
- `perage` требует Plan, результат стиха ~ Unit;
- [[Лады как монады|маска способностей]] проверяется статически (Lift переключает моду на аутентичную);
- типы: Var/Num/Str/Bool/Unit/Genus/Corpus/Field/Plan/Cmd/Fun; хинты = строки `Value::ty()`.

## 2. Рифменные ограничения (спетые стихи)
- строки одной метки несут одну типовую переменную — **унифицируются**;
- вольта-куплет (строки 7–8) несёт тип результата стиха `M a` — собственный тип bind'а строки 7 для рифмы не учитывается (потому доксология перед `perage` легальна);
- `pone`/`mitte`-строка «поёт» тип аргумента, биндит Unit.

Диагностика говорит стихами: `lines 1 and 3 rhyme on 'A' but do not unify — type clash: want num, got record`.

Исторический факт: первая схема кантуса (ABABABCC) сама оказалась диссонантной — рифмовала Corpus с Num; перемечена в AABCCB/AABBCC с антифонными строками-эхо ([[Метеорный скор]]).
