# Фуга как Reader

Фуга **не поётся** — её держит орган. Вычисление фуги даёт `Env` (`officium-core/src/env.rs`), против которого поются стихи:

- **pedale** — педальная точка: физическая константа (`pedale G = 6.674e-11`), читается `ask "G"`; педали видны и как свободные переменные (машина: скоуп → билтины → педали);
- **subiectum** — субъект: главное определение с параметром;
- **reale** `имя @ genus` — реальный ответ: точный оверлод (субъект октавой выше);
- **tonale** `имя @ genus` — тональный ответ: коерция (может вплести контрсубъект — например outgassing для комет);
- **contra** — контрсубъект: терм, звучащий всегда (r² при законе тяготения);
- голоса = размер окружения.

`resolve имя genus` — разрешение оверлода: сначала reale, потом tonale, иначе `Unresolved`. **Оверлод вычисляется в лексическом скоупе вызова** — его свободные переменные (параметр субъекта, педали) видят биндинги стиха. [[Тайпчекер — рифма это унификация|Чекер]] типизирует его там же.

Стретто — субъект, входящий над собой до конца предыдущего проведения, — это сигнал рекурсии (`Fix`, см. [[Core IR]]).
