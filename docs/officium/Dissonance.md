# Dissonance

`officium-core/src/types.rs` — всё, что может пойти не так (или просто просигналить):

| вариант | смысл | провал? |
|---|---|---|
| `WrongMode { mode, op }` | в [[Лады как монады\|башне лада]] нет слоя для операции | да |
| `Unresolved { name, genus }` | нет real/tonal ответа ([[Фуга как Reader]]) | да |
| `Silent` | Protus `nihil` — «коррекция не нужна» | **нет** (сигнал) |
| `User(value)` | Deuterus `clama`, ловится `recipe` | да |
| `Dissonant { want, got }` | рантайм-конфликт типов | да |
| `Premature` | commit пустого плана ([[Граница чистоты]]) | да, громко |
| `Unconsecrated` | commit не-плана | да, громко |
| `UnboundVar { name }` | имя не в скоупе/билтинах/педалях | да |
| `OutOfFuel(Continuation)` | топливо кончилось, возобновляемо ([[CEK-машина и топливо]]) | **нет** (сигнал) |
| `Parse { line, msg }` | диагностика парсера; у [[Транскрипция\|транскрипции]] line = номер ноты | да |
| `Discors { versus, msg }` | статический отказ [[Тайпчекер — рифма это унификация\|чекера]] (M7) | да, до первой ноты |
