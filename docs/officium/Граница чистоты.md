# Граница чистоты

Вся игра Officium. Только **миксолидийский** (VII) лад двигает настоящую гравитацию; **гипомиксолидийский** (VIII) чисто *планирует*:

- `mitte e` — добавить `GravityCmd` (или целый `Plan`) в растущий план. Чисто: моноид команд под конкатенацией.
- `perage e` — **единственный impure-примитив**: закоммитить план. Машина сама мир не трогает — она лишь кладёт план в `VerseOutcome.committed`, а **драйвер** ([[celebrare]], [[Хост-раннер]]) отдаёт его в `Platform::gravity_sink` — единственный аудируемый шов наружу.

## Охраны (громкие, это ядро игры)

- `perage` пустого плана → `Dissonance::Premature` — «спеть VII лад раньше времени — разорвать Землю»;
- `perage` не-плана → `Unconsecrated`;
- `perage` вне миксолидийского → `WrongMode` ([[Лады как монады|маска]]);
- с M7 `perage` не-плана ловится и статически ([[Тайпчекер — рифма это унификация]]).

Трейт `Platform` (gravity_sink, now, say) спроектирован под будущий переезд на syscall-транспорт (userspace).
