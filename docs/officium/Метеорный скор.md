# Метеорный скор

Референс-программа (§14): планетарная защита в трёх ладах, воплощает [[Граница чистоты|границу чистоты]]. Два файла в `officium/scores/`:

- **meteor.off** — [[Плоская форма]];
- **meteor_cantus.off** — та же семантика в [[Литургическая форма|8 спетых строках]], псевдолатынь.

## Пайплайн
1. **correctio** `in Re` (Protus/Maybe): тело → поле отклонения или `nihil` («уже безопасно»);
2. **consilium** `in sol` (гипомиксолидийский/Plan): поле → план команд, чисто, `mitte`;
3. **executio** `in Sol` (миксолидийский/IO): `perage plan` — единственная impure-строка.

Фуга **gravitas**: педаль `G = 6.674e-11`, субъект `trahere` (закон тяготения), reale для астероидов, tonale для комет (+outgassing 0.1), контрсубъект r².

## Контрольные числа (моки [[Билтины|билтинов]])
- астероид (1e20 кг, 1e5 м): dv = **0.3337**;
- комета (5e19, 2e5): dv = **0.0917125** (тональный ответ + outgassing);
- камешек (1.0, 1e9): **nihil**.

## Схемы рифм кантуса (честные по типам, см. [[Тайпчекер — рифма это унификация]])
- correctio: **AABCCB DD** — A=Corpus (антифонное эхо `testis <- pure corpus`), B/C=Num, DD=si-куплет;
- consilium, executio: **AABBCC DD**; executio набита доксологией Gloria Patri, `perage` в последней строке — «Per omnia saecula saeculorum».
