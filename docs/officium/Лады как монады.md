# Лады как монады

| Финал | Лады (аутент. / плагал.) | Монады | Операции |
|---|---|---|---|
| **Re / D** (Protus) | дорийский / гиподорийский | `Maybe` / `MaybeT` | `nihil`, `si…tunc…aliter` |
| **Mi / E** (Deuterus) | фригийский / гипофригийский | `Either` / `ExceptT` | `clama` (throw), `recipe` (catch) |
| **Fa / F** (Tritus) | лидийский / гиполидийский | `State` / `StateT` | `lege` / `pone` |
| **Sol / G** (Tetrardus) | миксолидийский / гипомиксолид. | `IO` / `Plan (Writer)` | `perage` (commit), `mitte` (emit) |

В v1 это **не** отдельные типы монад, а одна конкретная монада Run + **маска способностей** (`Mode::allows(op)` в `officium-core/src/types.rs`): «нельзя `pone` в дорийском стихе» — истина без башни трансформеров. Нарушение = `WrongMode` ([[Dissonance]]), с M7 ловится и статически ([[Тайпчекер — рифма это унификация]]).

Заголовок стиха выбирает лад: `versus x in Re` — дорийский, `in re` — гиподорийский ([[Аутентичный и плагальный|регистр = аутентичность]]).

Настоящая башня `MaybeT/ExceptT/StateT/WriterT` — несделанная веха M9 ([[Вехи Officium]]).

Лады — это буквально белоклавишные звукоряды на своих финалах ([[Таблица степеней]]): рендер не метафора.
