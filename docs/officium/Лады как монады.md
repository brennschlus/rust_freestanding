# Лады как монады

| Финал | Лады (аутент. / плагал.) | Монады | Операции |
|---|---|---|---|
| **Re / D** (Protus) | дорийский / гиподорийский | `Maybe` / `MaybeT` | `nihil`, `si…tunc…aliter` |
| **Mi / E** (Deuterus) | фригийский / гипофригийский | `Either` / `ExceptT` | `clama` (throw), `recipe` (catch) |
| **Fa / F** (Tritus) | лидийский / гиполидийский | `State` / `StateT` | `lege` / `pone` |
| **Sol / G** (Tetrardus) | миксолидийский / гипомиксолид. | `IO` / `Plan (Writer)` | `perage` (commit), `mitte` (emit) |

С M9 это **настоящая башня трансформеров** (`Mode::tower()` в `officium-core/src/types.rs`): у каждого лада — стек слоёв, эффекты живут в слоях, и легальность операции — теорема структуры, а не таблица-маска:

| лад | башня (сверху вниз) |
|---|---|
| дорийский | [Maybe] |
| гиподорийский | [Maybe, Maybe] |
| фригийский | [Except] |
| гипофригийский | [Except, Except] |
| лидийский | [State] |
| гиполидийский | [State, State] |
| миксолидийский | [Commit] |
| гипомиксолидийский | [Writer] — **сознательное исключение**: под чистым планировщиком ничего нет, лифт в commit был бы дырой в [[Граница чистоты\|границе чистоты]] |

`Mode::allows(op)` теперь выводится из башни («op легален ⟺ есть слой, его дающий; lift ⟺ есть слой ниже») — таблица v1-маски воспроизводится дословно. Нарушение = `WrongMode` ([[Dissonance]]), с M7 ловится и статически ([[Тайпчекер — рифма это унификация]]).

Заголовок стиха выбирает лад: `versus x in Re` — дорийский, `in re` — гиподорийский ([[Аутентичный и плагальный|регистр = аутентичность]]).

Лады — это буквально белоклавишные звукоряды на своих финалах ([[Таблица степеней]]): рендер не метафора.
