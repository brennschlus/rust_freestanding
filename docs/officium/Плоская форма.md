# Плоская форма

Канонический текстовый синтаксис (§7.1 спеки), строко-ориентированный ASCII. `officium-parse`: лексер (`lexer.rs`) + рекурсивный спуск (`parser.rs`), lowering сразу в [[Core IR]].

```
fuga gravitas in Sol {
  pedale     G = 6.674e-11        ; комментарий
  subiectum  trahere(corpus) = \r -> G * mass(corpus) / (r * r)
  reale      trahere @ asteroides = ...
  tonale     trahere @ cometes    = ...
  contra     \r -> r * r
}
versus correctio in Re {
  corpus <- arg
  si (safe corpus g) tunc { nihil } aliter { amen (deflect dv) }
}
```

Ключевое:
- ньюлайны значимы (завершают stmt/expr), кроме как внутри скобок;
- `;` — комментарий до конца строки, **кроме** литургического начала строки ([[Литургическая форма]]);
- регистр финала = аутентичность: `Re` дорийский, `re` гиподорийский ([[Аутентичный и плагальный]]);
- аппликация соположением (`solve f r`), операторы `+ - * /` → [[Билтины|билтины]];
- `si` — только последний stmt, рукава несут кадансы;
- `leva e` (M9) — лифт трансформера ([[Аутентичный и плагальный]]); `pone e` работает и как выражение (даёт unit), чтобы жить внутри `leva (pone e)`;
- depth-guard `MAX_EXPR_DEPTH = 96` — парсер спускается по нативному стеку, а стеки ядра конечны (см. [[Bootloader и старт ядра|историю с 512 КиБ]]);
- фуззинг: кривой ввод никогда не паникует, всегда `Dissonance::Parse`.
