# Транскрипция

M8 (§8.1–8.3), `officium-audio/src/transcribe.rs`: **аудио-вход**. Сыгранная на мануале фраза → текст [[Плоская форма|плоской формы]] → обычные парсер и [[Тайпчекер — рифма это унификация|чекер]]. Аудио — просто третий синтаксис.

## Восстановление лада (§8.1, историческое правило)
- **Финал** = pitch class ПОСЛЕДНЕЙ ноты (каданс). Не D/E/F/G → отказ «cadentia extra modos».
- **Амбитус**: мелодия ныряет ниже каданса → плагальный, иначе аутентичный ([[Аутентичный и плагальный]]).
- Якорь — сам каданс: играть можно **в любой октаве**.

## Инверсия
Каждая нота — ступень относительно каданса (`degree_offset`), ступень → операция (`op_of_degree`, [[Таблица степеней]]). Поток операций разбирается как точная инверсия [[Рендер|walk_verse]]: stmt'ы до каданса; нота Branch открывает `si`, оба рукава которого кадансируют сами (рекурсия, вложенные si работают).

## Канонический скелет
Мелодия недоопределяет слова — выбор фиксирован: `arg`→`v<-arg`; `ask "Dominus"` (+ генерируется фуга organum: `pedale Dominus = <речитативный питч>`, `reale vox @ cantus = \x -> x`); `pure vprev`; `v <- vprev`; `resolve "vox" (genus (corpus 0 "cantus" 0 0))`; Modal → `pone` (Fa), `mitte (cmd p p p)` (гипомиксолидийский), иначе плоский bind; каданс → `amen vprev`. Диссонантную импровизацию честно отвергает чекер.

Ошибки — `Dissonance::Parse` с **line = номер ноты**: хроматизм («nota extra modum»), ноты после каданса («cantus post amen»), фраза без каданса.

В ядре — команда `transcribe` ([[Шелл]]): ноты звучат при игре, Enter = каданс, транскрипт печатается и празднуется через [[celebrare]]. Раскладка мануала: [[Клавиатура i8042]].
