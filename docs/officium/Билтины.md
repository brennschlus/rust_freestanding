# Билтины

`officium-core/src/builtins.rs` — чистые хост-функции, каррируемые (`Value::Builtin` копит аргументы до арности). Вся физика — MOCK за таблицей, ядро сможет подменить.

| имя | сигнатура | заметки |
|---|---|---|
| `add sub mul div` | Num→Num→Num | операторы `+ - * /` лоуэрятся сюда |
| `eq` | α→α→Bool | полиморфный |
| `le lt` | Num→Num→Bool | |
| `not` | Bool→Bool | |
| `dist mass outgassing` | Corpus→Num | corpus = Record; outgassing по умолчанию 0.1 («кометы газят») |
| `genus` | Corpus→Genus | |
| `safe` | Corpus→Num→Bool | поле < SAFE_FORCE (1e-3) |
| `solve` | (α→Num)→α→Num | применяет закон силы, потом Δv = сила × SOLVE_K (0.5); единственный билтин, применяющий замыкание (BuiltinResult::Apply) |
| `deflect` | Num→Field | |
| `target dv_of at` | Field→Num | |
| `cmd` | Num→Num→Num→Cmd | |
| `plan_of` | Field→Plan | |
| `corpus` | Num→(Genus\|Str)→Num→Num→Corpus | конструктор тела |

⚠️ Таблица сигнатур в [[Тайпчекер — рифма это унификация|check.rs]] обязана совпадать с `builtins::arity` — есть тест-синхронизатор.
