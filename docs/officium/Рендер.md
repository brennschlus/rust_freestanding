# Рендер

`officium-audio/src/render.rs` (§8.4): программа «читается вслух» — IR → `Events` (Note {pitch, onset, dur, voice}) → трейт `Organ` (в ядре — [[AC97 драйвер|AC97-синтезатор]] через KernelOrgan, на хосте — MockOrgan с логом).

- **Голоса**: 0 — педальная точка (финал − 2 октавы, держится под экспозицией), 1 — субъект фуги (мотив 1-5-3-1), 2+ — стихи по очереди.
- **Стих**: обход bind-спайна — одна нота на строку, класс выражения (`classify`) → операция → ступень по [[Таблица степеней|таблице]]. Каданс держится 2 тика и ложится на финал. `si` — нота Branch, затем оба рукава подряд.
- Темп: `TICK_US = 250_000` (тик = ¼ секунды); `play()` шагает по тикам, включая/выключая ноты.
- `pitch_hz` — равномерная темперация через libm (A4=440).

Обратная операция — [[Транскрипция]]: раундтрип render → transcribe → parse → render даёт ту же мелодию (тест на всех стихах обоих скоров).
