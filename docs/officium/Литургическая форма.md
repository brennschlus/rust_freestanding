# Литургическая форма

M6 (§7.3): стих можно **петь** — восемь строк вида

```
A "Corpus errans in caelo videtur"      ; corpus <- arg
```

`метка "спетый текст" ; statement`. Текст — то, что поёт хор; стейтмент — что это значит. Сахар: lowering даёт ровно те же bind-цепочки, что [[Плоская форма]].

## Механика
- **Лексер**: `;` становится разделителем только если строка начинается с [Ident(одна заглавная), Str] — иначе комментарий как всегда. Второй `;` на строке — снова комментарий.
- **Парсер** (`liturgical_strip`): детект по Ident+Str после `{`, проход до парного `}`, тройки метка/текст/`;` выдираются из потока токенов, схема рифм пишется в `Versus::rhymes: Vec<(char, String)>`, остаток парсится обычным `stmts`. Stmt может перетекать на следующую спетую строку (si-куплет: строка 7 кончается `aliter {`, строка 8 несёт `amen … }`).

## Структурные проверки
1. ровно 8 строк («a verse is sung in eight lines»);
2. вольта-куплет (строки 7–8) рифмуется — одна метка;
3. каждая рифма отвечена (метка ≥ 2 раз).

Типовую честность рифм проверяет [[Тайпчекер — рифма это унификация]]. Референс: [[Метеорный скор|meteor_cantus.off]]. В ядре `celebrare cantus` печатает поэму построчно.
