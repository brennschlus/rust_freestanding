# Officium — обзор

Тьюринг-полный функциональный язык, где музыкальная структура — семантика. Связывает четыре вещи, которые все приходят восьмёрками: восемь григорианских ладов, восьмистрочный стих, монастырь и орган.

- [[Лады как монады|Восемь ладов = семейства монад]], сгруппированы вокруг четырёх финалов (Re/Mi/Fa/Sol).
- [[Фуга как Reader|Фуга]] не поётся — её держит орган: это Reader-окружение (педали-константы, субъект, оверлоды).
- [[Стих как bind-цепочка|Стих]] — монадический пайплайн из 8 строк; каданс в тонику = `return` + останов (`amen`).
- [[Граница чистоты]] — вся игра: только VII лад (`perage`) трогает мир, VIII лишь копит план.
- Тьюринг-полнота: λ + аппликация, рекурсия через **стретто** (`Fix`), ветвление, память Tritus-State. Проблема останова = кадансирует ли фуга — «только Бог знает финальный Amen».

Три поверхностных синтаксиса, все сводятся к одному [[Core IR]]:
1. [[Плоская форма]] — текст;
2. [[Литургическая форма]] — 8 спетых рифмованных строк;
3. [[Транскрипция]] — живая игра на мануале.
