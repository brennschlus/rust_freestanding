# Стих как bind-цепочка

Стих — функция своего входа (`arg`), опускающаяся в цепочку монадических bind'ов и заканчивающаяся **кадансом**:

- `x <- expr` — bind;
- `pone e` / `mitte e` — модальные stmt'ы (значение — Unit, биндер `_`);
- `si e tunc { … } aliter { … }` — ветвление, только последним stmt'ом (рукава несут свои кадансы);
- кадансы: `amen e` (Return: выдать и остановиться), `nihil` (Protus-обрыв), `clama e` (бросок), `perage e` (commit — [[Граница чистоты]]).

**Вольта** — поворот к финальному куплету, где собирается результат: в [[Плоская форма|плоской форме]] просто последние строки, в [[Литургическая форма|литургической]] — граница строк 6→7, в [[Транскрипция|мелодии]] — нота-октава (Branch).

Каноничный стих — 8 строк ([[Литургическая форма]]); плоская форма длину не ограничивает.

В [[Core IR]] это `Bind(mode, m, x, k)` со сплайсом продолжения; исполняет [[CEK-машина и топливо]].
